# АТМ Альянс (atm72.ru): исследование конкурентов и прототипы

Конкурентный анализ и прототипы четырёх типов страниц: главная, раздел каталога («Роботы-уборщики»), карточка товара (Pudu CC1) и страница услуги («Заправка картриджей в Тюмени»). Ниши: роботы-уборщики, LED-плёнки, медиакубы, заправка картриджей. Сначала исследование, потом прототип.

**Смотреть прототипы:** https://takedown-desing.github.io/atm72-prototype/

**Обоснование блоков со скриншотами конкурентов:** https://takedown-desing.github.io/atm72-prototype/rationale.html

## Пометки на блоках

Каждый блок в прототипах подписан ярлыком в левом верхнем углу:

* серый «Существующий блок»: есть на сайте сейчас, переработан;
* зелёный «Новый блок: по результатам исследования»: добавлен после разбора конкурентов и спроса;
* серо-зелёный: существующий блок, дополненный по исследованию.

Главная собрана от текущего шаблона сайта: существующие блоки воспроизведены в том же порядке, новые добавлены между ними, а не вместо них.

Кнопка «Скрыть пометки» в верхней панели убирает ярлыки. Мобильная версия: сузьте окно до 720 px или откройте с телефона.

## Как проводилось исследование

1. Запросы взяты из проекта TopVisor 30397470 как есть: все 310 фраз, 88 групп, без добавления своих. Частотность из TopVisor (Wordstat Москва и Тюмень), для 134 фраз без частоты взята частота из кластеризации.
2. Выдача: Arsenkin check-top по всем 310 запросам в трёх системах (Яндекс Desktop Москва 213, Яндекс Desktop Тюмень 55, Google Desktop Москва), ТОП-10. Arsenkin commerce по всем 310 (коммерциализация и геозависимость). Arsenkin iks по 56 доменам.
3. Спрос: Wordstat API, хвосты по 12 головным фразам, сезонность по месяцам за 24 месяца, отдельно регион Тюмень для заправки. Яндекс.Вебмастер: реальные показы и клики сайта за 2 недели.
4. Обход atm72.ru: 29 страниц всех типов (главная, каталог, разделы, карточки, брендовые подразделы, услуги, компания, контакты, новости, СМИ, карта сайта) с матрицей блоков.
5. Обход 32 сайтов конкурентов из выдачи (по 8 на нишу) по типам страниц: главная, каталог, карточка, услуга, цены, о компании, контакты, отзывы, кейсы, доставка. Скриншоты блоков.

Ограничения: Ahrefs и Keys.so недоступны в этой сессии, DR и органический трафик не сняты; авторитет оценивается по ИКС. Google-позиции в TopVisor не собирались, Google-выдача только из Arsenkin.
