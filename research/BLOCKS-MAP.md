# Карта блоков прототипов atm72.ru

Статусы: **old** существующий блок (на сайте сейчас или уже свёрстан в макете публикации текста, в прототипе без изменений); **res** новый блок по результатам исследования; **mix** существующий блок, дополненный по исследованию. Внутренние страницы собраны из макетов `публикация-текстов/макет-*.html`, переданных программисту: их блоки сохранены, новые вставлены между ними теми же элементами вёрстки (карточки, таблицы, чипы, таймлайн, аккордеон). «Откуда взято» указывает сайты из ТОП-10, у которых блок подсмотрен, и данные исследования. Скриншоты примеров: `rationale.html`.
